# 三维表面标注与优化版 05

本版提供随旋转保留的三维表面标注，继续使用 20–25 岁亚洲成年女性的固定体表模型。三维与二维课件分别保存，旧二维课件仍可打开。

## 使用方法

1. 在查看器上方“三维表面标注”选择工具，先填文字，再点模型。**定位与文字**点一次；**两点连线**依次点两个位置；**体表描线**按住拖画，可选择闭合成圈。
2. 完成一条后自动进入选择模式。点**旋转观察**，即可旋转、缩放和观察，三维标注仍在原部位。
3. 需要继续修改时，点**选择 / 拖动**，直接点标注，或在“已有标注”列表选择。拖端点会重新贴到体表；拖文字改变标签位置；拖线或 **Shift 拖动标注**可整体移位。
4. 用“文字 / 点 / 线宽大小”反复调整显示大小；“描线范围 ＋ / −”缩放描线或两端点的范围。连线长度也可通过拖端点改变。Alt＋滚轮可调整选中标注的显示大小。
5. 两点连线可改弧度、末端箭头、贴合体表，以及是否显示等分刻度；段数可选 2–20。支持单条隐藏、全部隐藏、遮挡自动隐藏、删除、清空、撤销与重做。
6. **关闭前点“保存三维课件”**，下载 JSON。下次打开同一版查看器后点“导入三维课件”，可以继续调整。导入会保留现有工作并追加标注，不覆盖当前内容。查看器打开时默认正面，后侧标注需要旋转到相应方向才显示。

默认启用身体遮挡。转到背面时，正面的标注会隐藏，转回时重新出现。文字采用面向观察者的标签，颜色、描边与底色便于在不同背景下辨认。三维标注显示大小可调，文字保持便于阅读的屏幕尺寸，不会因无限放大模型而无限变大。

## 曲线、刻度与边界

两端点用三角面与重心坐标绑定体表，不是只保存在截图上的像素位置。曲线可向两侧弯曲；“贴合体表”通过当前表面投影近似实现，不是严格的皮肤测地线。

跨越身体空隙或投影发生明显跳跃时，显示空间曲线并提示，两个端点仍绑定体表。空间曲线可能被身体遮挡，可换视角或调整弧度；不要把穿过身体的部分当作内部解剖路径。

等分刻度按**当前显示曲线的弧长近似等分**，用于教学分段；它不是毫米刻尺，也不是临床测量。原有“两点直线测距”仍是模型值，与本功能分开。

描线请沿连续可见的体表分笔绘制，跨越身体空隙时另起一笔。

课件最多 120 条标注，单笔最多 512 个采样锚点，文字最多 80 字，导入 JSON 上限 8 MB。暂停或取消未完成的两点连线时，尚未完成的第一点不会保存。

## 背景与外形

背景提供**暖白、浅暗蓝灰、更浅暗灰**三档，切换时不改变灯光强度、模型材质或标注颜色。轮廓线和标签描边有助于在不同底色上观察。

模型取消刘海和马尾，保留贴头短发与前额、后颈弧形发际线；调整上唇体积、唇色和嘴角，呈轻微微笑。补充肚脐、髌周轮廓、腘横纹、掌侧腕横纹与腋前皱襞的浅表起伏。新增肚脐、腘窝、掌侧腕部的观察视角。

这些横纹与起伏是当前固定姿势下制作的柔和体表示意，不是扫描数据或医学专家校核结果。它们没有用深色粗线刻画；建议用局部视角、斜向观察和适度放大查看。

## 与原有二维标注、Excalidraw 的关系

| 功能 | 三维表面标注 | 二维截图板书 |
| --- | --- | --- |
| 随旋转保留位置 | 支持 | 固定在截图上 |
| 保存后继续编辑 | 三维课件 JSON | 二维课件 JSON |
| 4K PNG | 含当前可见的三维标注 | 含当前快照与二维笔迹 |
| 可编辑 Excalidraw | 通过固定视角截图呈现 | 二维笔迹可编辑 |

“二维截图板书（固定视角）”会把当时可见的三维标注一起拍入背景；再添加的二维笔迹仍独立可编辑。返回 3D 后，原来的三维锚定标注仍可旋转和修改。

旧的二维笔迹不会自动转成三维锚点；单张截图无法可靠确定所有笔迹对应的三维位置。Excalidraw 文件也不能保存本查看器的原生三维锚定关系；请同时保存三维课件 JSON。Obsidian 中可继续使用本项目的本地网页嵌入方式，在查看器里交互，详见集成说明；本轮未在 Obsidian 应用内实测。

人体 GLB 与查看器的三维课件 JSON 分开保存；单独用其它软件打开 GLB 不会显示这些查看器标注。

三维课件会核对模型指纹。更换网格、姿态或模型版本后不能直接套用旧锚点，以免错位；请在新模型上重新定位。本版不提供骨骼动画或软组织随动作变形。
