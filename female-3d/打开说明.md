# 女性 3D 体表样稿

这是可旋转的三维网格，不是二维三视图动画。模型采用亚洲成年女性外观形变，穿不透明运动上衣及中长贴身短裤。

## 在电脑上打开

1. 下载本目录的 `female-3d.html` 完整文件，或下载仓库中的 `female-3d-offline.zip` 并解压。
2. 用桌面版 Chrome 或 Edge 双击打开 `female-3d.html`。优化版包含 4K 贴图，HTML 约 54 MB，请先完成下载。GitHub 的文件预览页不能运行 HTML。
3. 左键拖动旋转，滚轮缩放，右键拖动平移；触屏可以双指缩放。

查看器把程序、模型和眼部贴图全部嵌入同一个 HTML，无外部 CDN，无需联网加载。某些公司的浏览器策略禁止本地 HTML 或 WebGL。如遇限制，可安装 Python 后，在此目录运行 `python -m http.server 8000 --bind 127.0.0.1`，再在浏览器地址栏输入 `http://127.0.0.1:8000/female-3d.html`。这仅在自己的电脑提供本地服务，不是线上预览。

## 本版功能

- 教学标注：选定三维视角后创建 4K 快照课件，使用画笔、荧光笔、箭头、矩形、椭圆和文字；支持选择移动、对象擦除、删除、撤销及重做。
- 多页课件、JSON 保存与恢复、带标注 4K PNG、可编辑 `.excalidraw` 导出。
- [Obsidian / Excalidraw 集成说明](Obsidian与Excalidraw教学.md)，含本地启动器与网页嵌入示例。标注属于固定视角，不是跟随三维曲面的锚点。
- 正面、背面、左右侧面、肩背局部聚焦、全身复位。
- 自然肤色与石膏研究模式、线框拓扑、观察区域示意标记。
- 自动旋转、透视与正交切换、地面网格。
- 两点空间直线测距。数值属于合成模型，不是人体实测值或沿体表的弧长。
- 导出当前视角的 4096 像素宽 PNG，不包含界面与文字标记。原生截图不作 300 DPI 印刷质量承诺。

教学模式的“导出带标注 4K PNG”会包含自己添加的笔迹和文字；原有 3D 模式的截图按钮保持纯模型截图。

## 模型与精度

`assets/asian-female.glb` 可独立导入支持 glTF 的三维软件；`assets/asian-female.blend` 可用 Blender 4.3+ 编辑。体表基础网格来自 MakeHuman 的 CC0 资产，使用其成年女性亚洲外观形变。外观参数不代表亚洲女性的人体统计标准，也不是某个真实人物的扫描。

合成体表身高设为 165 cm（不含发髻）。基础体表 13,380 个顶点、13,378 个面，细分后 428,096 个体表三角面。优化版连同头发、眼部共 457,624 个三角面；服装直接作为同一体表上的不透明贴图，没有独立衣片厚度。详见 [优化版 03](优化版03说明.md)。细分与程序微纹理不增加经过验证的解剖信息。

新版离线包只包含查看器、本地启动程序、说明和预览，不重复放入已经内嵌的模型与贴图。GLB、Blender 可编辑文件以及开发代码保存在仓库中，可以独立下载。

本版以体表观察和交互试用为目标。肩胛冈和肩峰角位于皮下，不能凭体表外观准确检查其骨性曲面。本版没有内部骨骼、肌肉、关节运动或医学断面，不提供“透过皮肤看到虚构骨骼”的功能。后续如需骨性细节，必须加入有来源、授权合适且经过专业校核的独立骨骼数据。

## 来源与重建

资产来源、固定提交与 SHA-256 见 `assets/provenance.json`。许可原文保存在 `licenses/`，汇总见 `THIRD_PARTY_NOTICES.md`。

以下重建命令需要完整仓库；轻量离线查看包不包含开发源文件。

重建模型：安装 Blender 4.3+，在本目录执行 `blender -b --python scripts/build_model.py`。

重建查看器：安装 Node.js 20+，执行 `npm ci`，再执行 `npm run build`。重建时需要下载 npm 依赖；使用已生成的 HTML 无需这些开发工具。
