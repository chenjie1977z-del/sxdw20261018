# 优化版 06：三维图形工具、右键菜单与参考头像

下载仓库根目录 `female-3d-offline.zip`，解压，用桌面 Chrome / Edge 打开 `female-3d/female-3d.html`。本版仍为 20–25 岁成年女性体表样稿。

## 创建与修改三维图形

工具位于左栏顶部。先选工具，按下面的顺序点人体表面；描线则按住拖画。工具完成一条标注后会自动进入“选择 / 拖动”，继续绘制时重新选工具。

| 工具 | 创建方法 | 再次调整 |
| --- | --- | --- |
| 点 | 点一个体表位置 | 拖动点重新贴肤 |
| 定位与文字 | 输入文字，点体表位置 | 拖动文字框或体表定位点 |
| 直线 | 依次选两个端点 | 拖端点；可选贴肤、箭头、等分刻度 |
| 弧线 / 刻度 | 依次选两个端点 | 拖端点，调弧度、箭头和等分段数 |
| 圆 | 先点圆心，再点半径位置 | 拖圆心或半径点；可用“图形范围 ＋ / −”缩放 |
| 三角形 | 依次点三个顶点 | 拖三个控制点 |
| 长方形 | 依次点两个对角点 | 拖两个对角控制点 |
| 体表描线 | 按住鼠标拖画 | 拖首尾控制点、缩放范围，可闭合 |

选择模式下，拖线条可整体移位；按 Shift 拖动任意部分也可整体移动。所有位置保存在三角面及其重心坐标中，旋转和缩放视角不会把标注留在屏幕上。换视角后仍可反复修改。

圆和长方形以创建时的观察平面确定方向，之后不会随相机重新朝向。启用“连线贴合体表”时，图形轮廓会投射到曲面，因此在弯曲皮肤上的圆或矩形可有曲面变形。关闭该项可保留空间中的几何轮廓，控制点仍锚定体表。跨越身体空隙或凹陷过深时会回退到空间轮廓，并显示提示。它们用于教学示意，不是测量圆、面积或人体长度的工具。

右键拖动仍用于平移；按下右键后拖动超过约 5 像素时不弹出菜单。空白区域右键可恢复正面、看背面或面部、添加常用图形、切换背景、显隐全部标注、导出 4K PNG 或保存课件。右键点已有标注可重命名 / 修改文字、删除、缩放文字框或图形、隐藏标注。隐藏后可从左侧列表选中，再打开“显示选中标注”。删除与修改可撤销。

## 文字框大小

从左侧列表选中标注，或进入“选择 / 拖动”点标注。文字框右下角出现蓝色缩放手柄，按住拖动可同时调整宽、高；拖文字框本身则只移动位置。左栏另有“文字框宽”“文字框高”和“文字字号倍率”，可分别调整。框内文字自动换行，并在必要时缩小字号以适应边界。

“标注整体大小”仍控制整条标注的点、线和文字大小。文字框宽、高是整体倍率为 1 时的屏幕像素，随相机缩放保持可读。标签指针线已从原线半径的 60% 调细到 22%，与主体线条区分。以上设置随三维课件保存。

## 头像与兼容性

参考本次提供的正面头像，调整椭圆脸型、眉眼、鼻部与唇部，增加更浓密平缓的眉毛、中分后梳发流、细分缝、珊瑚色唇部和轻微露齿笑容。没有将参考照片直接作为脸部贴图或打包进文件。单张正面图不能确定侧面、后脑和真实三维尺寸，本版是外观方向的近似建模，不能视作精确复刻。

本版可以导入 05 版三维课件。兼容性检查逐项比较了 1,284,288 个三角面顶点的 UV 顺序，确认相同后，只开放已核实的 05 版模型指纹；锚点随新版体表位置更新，文字框位置和原大小保留。更早或任意外部模型的课件仍会拒绝导入，避免错位。核验记录见 `assets/anchor-compatibility.json`。

关闭前请分别保存“三维课件”和“二维课件”。三维几何标注可随快照进入二维板书与 PNG，但导入 Excalidraw 的三维标注属于截图像素；其后的二维文字和箭头仍可独立编辑。动态三维效果须在本查看器中使用。

模型的体表、发型与牙齿均为教学概念形态，未经过专业解剖或牙科校核。本次未修改原有 300 / 600 DPI 平面插图。
