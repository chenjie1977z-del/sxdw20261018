## 女性 3D 交互样稿

已提供亚洲成年女性体表的真实三维网格与离线查看器，可旋转、缩放、平移、切换标准视角、聚焦肩背、查看线框、测量两点直线距离，并导出 4K PNG。

现已加入**教学标注**：画笔、荧光笔、箭头、形状、文字、移动、擦除、撤销重做、多页课件，以及可编辑 `.excalidraw` 导出。先选定三维视角再标注；笔迹绑定视角快照，不随三维模型旋转。
