# A3 印刷文件说明

本目录提供三张图的精修源图、A3 PNG、LZW 无损压缩 TIFF，以及按男性、女性、骨骼顺序排列的三页 A3 PDF。

## 输出规格

| 项目 | 规格 |
| --- | --- |
| 成品页面 | A3 横版，420 × 297 mm |
| PNG / TIFF | 4961 × 3508 像素，300 DPI，8 位 RGB |
| 色彩 | PNG / TIFF 嵌入 sRGB ICC 配置 |
| 排版 | 等比例缩放并居中，白边约 10 mm 以上，不裁切、不拉伸 |
| PDF | 三页 A3，嵌入完整像素的 RGB 图像，无 JPEG 有损压缩 |

## 源图与真实细节

`sources/` 保留图像工具重新精修后的原生图像，仓库 `images/` 中的原有版本保持不变。

精修源图仍约为 1300–1500 像素宽。A3 文件使用 Lanczos 插值放大并设置 300 DPI；这符合所列文件尺寸和印刷排版规格，但不等于原生 300 DPI 的解剖细节。插值不会增加真实结构信息，AI 精修也可能改变细部。请在实际印刷尺寸下检查清晰度并打样，不能仅凭 DPI 数字判断出版质量。

这些是医学插图候选稿，骨骼结构、体表标志、指趾及引线标注尚需专业人员校核。正式医学出版所需的细节可能仍需医学插画师修订或重绘。

文件保持 RGB，未套用未经确认的 CMYK 印刷配置，也不是 PDF/X 交付件。交印前请由出版社或印厂依据纸张、印刷工艺及指定 ICC 配置进行色彩转换、软打样和最终预检。本版本采用白边版式，不包含裁切线或出血。
